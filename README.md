<summary><b>🔍 Click to view architectural overview: Enterprise RAG Knowledge Copilot</b></summary>
<br/>

- **Problem Statement:** Internal technical documentation and product specs often become fragmented across teams, making onboarding and discovery slow.
- **Solution Architecture:**
  1. **Document Ingestion:** Markdown and PDF docs are parsed and chunked using recursive character text splitters.
  2. **Vector Indexing:** Embeddings generated via lightweight embedding models and indexed in a vector store (Chroma/Qdrant).
  3. **Retrieval Chain:** LangChain semantic similarity retriever feeds context into prompt templates with strict citation constraints.
  4. **API Interface:** Exposes a clean FastAPI `/api/v1/query` endpoint for developer access.
